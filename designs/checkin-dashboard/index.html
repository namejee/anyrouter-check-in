A quick guide

怎样拿到新 Cookie？

  1. 在 AnyRouter 重新登录

    先登录你要更新的 GitHub 或 LinuxDO 账号。页面右上角的账号应与左侧选择一致。

  2. 用 Cookie-Editor 导出

    停留在 anyrouter.top，打开 Cookie-Editor，选择「Export → JSON」，复制完整内容。

  3. 粘贴，点击「更新并验证」

    会先检查 Cookie 对应的账号；另一个账号仍使用它自己的配置。需要更新两份时，分别操作一次。

没有 Cookie-Editor？可在开发者工具的 Application → Cookies 中复制 session，粘贴为 {"session":"复制的值"}。推荐完整导出，以便同时更新防护 Cookie。

这些状态是什么意思？

HTTP 401 · 登录失效

站点已拒绝旧的账号登录。重新登录并更新 session Cookie 即可；刷新 acw_tc 等防护 Cookie 无法恢复账号授权。Cookie 写死在代码里也会过期。

签到成功，为什么余额没有增加？

当天可能已经发放奖励，或到账发生在本轮读取之前。请看上方每日记录；重复签到不会重复领 $25。

到账了，余额为什么还下降？

余额还会受使用消耗影响。判定额度增加时会补回期间消耗，所以净余额下降也可能已经到账。

页面余额是不是实时的？

余额来自最近一次有效读取，读取时间显示在账号卡片上。点「立即补跑」可重新验证。GitHub 的定时执行可能延迟，计划时间不等于实际执行时间。
